## DETAILED EXPLANATION: heatmap_top_variable_genes.pdf

### What This QC Heatmap Shows

This heatmap displays the **500 genes with the highest expression variance across all 8 samples** (MDA-MB-231 n=4, HDF n=4, regardless of treatment).

### How It Was Generated

```R
# Step 1: Calculate variance for each gene across all samples
gene_var <- apply(expr_matrix, 1, var)

# Step 2: Select top 500 highest-variance genes
top_var_genes <- names(sort(gene_var, decreasing = TRUE))[1:500]

# Step 3: Extract expression for these genes
expr_top_var <- expr_matrix[top_var_genes, ]

# Step 4: Standardize (z-score) by row
expr_scaled <- t(scale(t(expr_top_var)))

# Step 5: Create hierarchical clustering heatmap
# - Row distance: Pearson correlation
# - Column distance: Euclidean
# - Linkage: Complete
# - Color scale: Red-Blue diverging (-3 to +3)
```

### What You See in This Heatmap

1. **Rows (Genes):** 500 genes selected purely on variance basis
   - Genes that vary most in expression across samples
   - NOT selected based on treatment response
   - Represents genes with high biological or technical variability

2. **Columns (Samples):** 8 samples
   - 4 MDA-MB-231 samples (color-coded)
   - 4 HDF samples (color-coded)
   - 2 treatment conditions per cell line (mock vs TP4)

3. **Color Coding:**
   - **Red:** High expression (positive z-score)
   - **Blue:** Low expression (negative z-score)
   - **White:** Mean expression (z-score ≈ 0)

4. **Annotations (Column headers):**
   - Cell line annotation (MDA vs HDF)
   - Treatment annotation (Mock vs TP4)

5. **Hierarchical Clustering:**
   - Genes cluster by expression similarity
   - Samples cluster by transcriptomic similarity
   - Tree structures reveal underlying data structure

### Quality Control Information Revealed

#### A. Sample Clustering Pattern
- **Expected:** Samples from same cell line cluster together
- **Biological Meaning:** Strong cell line effect dominates transcriptomics
- **Interpretation:** Data quality is GOOD if clear cell-line clustering visible

#### B. Gene Expression Patterns
- **High-variance genes** often include:
  - Housekeeping genes with inherent variability
  - Cell-type-specific genes (MDA vs HDF differ fundamentally)
  - Biologically regulated genes (fluctuate between cell states)
  - Potential batch effect markers (if technical variation present)

#### C. Outlier Detection
- Unusual sample clustering patterns = potential outliers
- Unexpected gene expression patterns = potential quality issues
- Mixed clustering = potential batch effects

#### D. Treatment Effect Preview
- Even though this plot is PRE-analysis, you might observe:
  - Slight TP4-treated sample clustering if effect is large
  - OR no clear treatment clustering (effect is small relative to cell-line effect)
  - This preview helps validate later DE findings

### Why "Top 500" and Not "Top 100"?

The choice of 500 genes is a **standard QC practice**:
- **Why 500?** Large enough to represent genome-wide patterns, small enough to visualize
- **Why variant-based?** Housekeeping/invariant genes add no information to QC
- **Not 100?** Would be too restrictive—might miss important QC signals

- Cell-line-specific markers (MDA vs HDF)

- ✗ One replicate far from others

Top 500 genes by variance likely driven by:
- **~60-70%:** Biological differences (cell-line identity)

## LEGEND RECONCILIATION: Why Figure 3 Legend Differs

### From FIGURE_LEGENDS.md (Figure 3):

> "Unsupervised hierarchical clustering heatmap displaying standardized (z-score) expression of the **top 100 genes from the interaction contrast plus top 50 genes from the MDA-specific TP4 response**, selected on the basis of statistical significance (FDR<0.05)."

### Key Differences in Gene Selection:

1. **Top 100 from interaction contrast:**
   - Interaction = (MDA-TP4 - MDA-mock) - (HDF-TP4 - HDF-mock)
   - These genes respond preferentially to TP4 in cancer vs. normal cells
   - Directly identify cancer-selective mechanism

2. **Top 50 from MDA-specific TP4 response:**
   - MDA-TP4 vs. MDA-mock
   - Genes most strongly induced/repressed by TP4 in cancer cells
   - Amplify the biological signal

3. **Selection criterion: FDR<0.05, |log₂FC|>0.585**
   - Statistical confidence: False discovery rate control
   - Biological minimum: ≥1.5-fold change
   - Excludes borderline/weak effects

### Why NOT "Top 500 Variable Genes"?

For publication, you want to show **treatment effects**, not just **gene variance**:
- Variable genes ≠ Significant genes
- A gene could vary naturally (biological or technical) without TP4 response
- Publication-quality figures must focus on validated findings
- 150 genes is readable; 500 is not

**The rule:** 
- QC plots = Show data quality (any measurable genes)
- Publication plots = Show biological findings (significant genes)

## RECOMMENDED VIEWING & INTERPRETATION

### When Reviewing This Heatmap:

1. **First Look:** Do samples cluster by cell type?
   - Yes = Good ✓
   - No = Potential quality issue ✗

2. **Second Look:** Are replicates grouped?
   - Yes = Good reproducibility ✓
   - Spread out = Variable quality ⚠

3. **Third Look:** Any obvious outliers?
   - No = All samples usable ✓
   - Yes = Investigate that sample ⚠

4. **Fourth Look:** Does treatment cause clustering?
   - Subtle = Expected (cell-line effect dominates) ✓
   - Strong = Large treatment effect (validate with DE analysis) ✓
   - None = No obvious treatment effect in top 500 (normal for QC) ✓

5. **Final Interpretation:**
   - If all above checks pass: "Data quality is GOOD. Proceed with DE analysis."
   - This was the actual conclusion in this dataset
